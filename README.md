# Conway's Game of Life

Conway's Game of Life is a GPU-accelerated cellular automaton simulation featuring an infinite canvas. Unlike typical simulations, this version allows you to change the rules in real time and instantly see the results. With unlimited zoom and pan, real-time rule customization, and hundreds of preloaded user templates, you can even upload your own starter templates for others to use. Dive into a visually stunning and endlessly customizable cellular automaton experience!

## Features
- **Custom Rule Sets:** Modify the rules of the simulation in real time.
- **GPU Acceleration:** Uses WebGL for smooth and efficient rendering.
- **Infinite Canvas:** Zoom and pan freely without limitations.
- **Preloaded Templates:** Choose from hundreds of user-generated patterns.
- **Upload Your Own Templates:** Share your unique creations with others.

## Installation
```sh
# Clone the repository
git clone https://github.com/Himanshu12102004/conwaysInfinite
cd conwaysInfinite/frontend

tsc-watch

```
Run using live preview of VSCode

## Usage
- Modify the rules of Conway’s Game of Life in real time.
- Load preloaded templates or upload your own.
- Zoom and pan across an infinite canvas.
- Experiment with different configurations and observe emergent behaviors.

## Technologies Used

- **TypeScript** for type safety
- **Custom Cellular Automata Rules** for enhanced flexibility
